# Sentinel Grid delivery outcomes

- Deliver a responsive Overview dashboard with live industrial gas readings, system health, current alert severity, LED/buzzer states, MQTT activity, and navigation across all operational sections.
- Deliver a dedicated 3D Simulation Lab with animated industrial control-room scenes, normal sensor drift, rising gas concentration, critical spike injection, runtime start/stop, automatic packet pause/resume, and packet inspection.
- Deliver Live Sensors for MQ-2, MQ-7, DS18B20, and DHT22 devices with selectable device views, current values, signal history, MQTT topic identity, device status, and connection controls.
- Deliver Node-RED-style local threshold evaluation that processes simulated packets and updates severity, LED indicators, and buzzer behavior in real time.
- Deliver Alert History with severity/status filtering, individual acknowledgement, acknowledge-all, event details, and CSV export.
- Deliver an MQTT Topics console with editable broker URL, active topic selection, connection/status presentation, per-topic packet counts, recent payload visibility, and test-packet publishing.
- Deliver Thresholds controls with sensor-specific sliders, LED and buzzer policy settings, immediate simulation feedback, and restore-defaults behavior.
- Deliver System Config with a 3D ESP32 gateway health visualization, runtime and packet preferences, simulation settings, and persisted local configuration.
